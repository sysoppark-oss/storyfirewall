# 검증 의뢰서 32차 — 원격 제어 사기 경보·AI 도구 감시 (2026-11-06)

대상: Story Firewall 제품 A (Windows 개인 방화벽, 이야기형 연결 분석). 공개 저장소 `sysoppark-oss/storyfirewall` (AGPL-3.0).
첫 출시의 얼굴 ①(원격 제어 사기 경보, 이야기형 14판 20-4)과 ③(AI 에이전트 감시, 20-5)의 1단계를 구현했다.
아래 설계가 **깨지는 입력·순서**를 먼저 적어 달라(공격자 관점). 맞다/틀리다 확인은 그다음이다.

## 1. 바뀐 것

| 번호 | 내용 |
| --- | --- |
| L072 | 원격 제어 사기 경보 1단계. 원격 도구 목록(TeamViewer·AnyDesk·RustDesk·Chrome 원격 데스크톱·빠른 지원·ScreenConnect)을 실행 파일 이름으로 알아본다. 10초마다 그 pid 의 외부(루프백 제외) 누적 송수신(conn_bytes)을 재서, 최근 30초에 600KB 이상 보냈고 보낸 양이 받은 양보다 크면 "세션 모양 시작" → 서비스 사건 + Windows 알림. 30초 송신 150KB 미만이 90초 이어지거나 프로세스가 끝나면 "끝". 이 PC 에서 남을 조작하는 쪽(받는 양이 큼)은 경보하지 않는다. 서비스 시작 전부터 돌던 도구는 1분마다 "최근 통신한 pid" 에서 다시 찾는다. 기준값은 추측이며 노트북 실측으로 고친다 |
| L073 | 세션이 끝나면 그 시각 범위의 PC 전체 사실(새 프로그램 실행 수, 명령 창, 설치 프로그램, 내려받은 파일, 자동 실행 등록)을 끝 문장에 붙인다. 원격 도구의 자손으로 좁히지 않는다(원격 조작은 이 PC 의 탐색기·브라우저로 일을 시킨다) |
| L074 | AI 도구 감시 1단계. 도구 목록(Claude·ChatGPT·Codex·Gemini CLI·Cursor·Windsurf·Ollama·LM Studio·따로 도는 MCP 서버)을 실행 파일 이름 또는 명령줄 패키지 이름(Windows npm 역슬래시 경로 포함)으로 알아본다. 뿌리 프로세스만(부모가 AI 도구면 그 트리 안). 사실은 설치 엑스레이와 같은 자손 트리 모으기(통신한 곳·실행한 명령·만든 파일·자동 실행). 5분마다 최근 7일을 미리 계산, 조회는 읽기만. 판정하지 않는다 |

## 2. 질문 (공격자 관점 먼저)

**Q1 (L072 세션 모양)**: 사기범이 경보를 피하는 순서를 적어 달라. 예: 화면 전송을 낮은 화질·낮은 프레임으로 30초 600KB 아래 유지, 보낸 양 ≤ 받은 양이 되게 상대 쪽에서 파일을 계속 밀어 넣기, 원격 도구 이름 바꾸기(이름만 맞춤), 목록에 없는 도구(국내 원격 지원 도구, 브라우저 기반 WebRTC 원격), RDP 들어오는 연결(지금 수집기는 들어오는 연결 선이 없다). 각 경우 대안 신호(입력 장치 주입, 화면 캡처 API, 세션 종류)와 드라이버 없이 가능한지.

**Q2 (L072 오탐)**: 사용자가 직접 연 원격 접속(회사 PC 에서 집 PC 접속 등)도 "시작" 알림이 뜬다. 20-4 는 "내가 한 것" 확인 + 기준선으로 줄이라고 했다. 기준선(평소 쓰는 도구·시간대)으로 조용히 하면 사기범이 바로 그 도구·시간대를 쓰는 경우를 놓친다. 어느 쪽이 덜 나쁜지, 알림을 "처음 한 번은 크게, 그 뒤 같은 도구는 작게" 같은 단계로 나눌지.

**Q3 (L073 세션 사실)**: PC 전체를 세면 세션과 무관한 백그라운드 실행(업데이트·백신)이 섞인다. 반대로 원격 도구의 자손으로 좁히면 원격 조작으로 탐색기에서 띄운 프로그램을 놓친다. 둘 사이의 기준(예: 대화형 세션 + 사용자 입력이 원격에서 온 시각대)을 제안해 달라.

**Q4 (L074 알아보기)**: 악성 프로그램이 이름을 `claude.exe` 로 하거나 명령줄에 `@modelcontextprotocol/` 를 넣어 "AI 도구"로 보이게 해 판정 화면에서 묻힐 수 있는가? (AI 도구 화면은 판정하지 않고 4장 판정은 따로 돈다 — 이 분리가 충분한지.) 반대로 진짜 AI 도구의 MCP 서버가 python·uv·docker 로 돌아 놓치는 경우.

**Q5 (L074 뿌리 고르기)**: 부모가 AI 도구면 뿌리로 세지 않는다. AI 도구가 띄운 셸이 다시 악성 프로그램을 띄우면 그 사실은 AI 도구 카드의 자손 목록에만 들어간다. 카드의 자손 상한(300)·명령 목록을 넘치게 해 진짜 행동을 숨기는 순서와 대책.

**Q6 (성능)**: AI 도구 미리 계산은 7일 안 프로세스 노드 전체와 ran 선 전체를 훑는다(노트북 노드 10만, 선 58만). 오래 켜 둔 데스크톱 앱(30일 안 끝 표시 없음)의 자손 트리를 매번 다시 모은다. 이 비용이 커지는 입력과 증분 방법.

## 3. 확인된 것
- 단위·통합 시험: 세션 추적기(유휴 유지 신호는 세션 아님, 화면 전송 시작·끝 시각, 받는 쪽은 경보 없음, 프로세스 끝, 누적 줄어듦), 그래프 조회(루프백 제외, 끝난 프로세스 제외), 세션 사실 범위, AI 도구 뿌리(자식 claude.exe·MCP 서버는 뿌리 아님, 명령줄로 알아본 Claude Code), 아직 도는 데스크톱 앱, agents.list(계산 전 ready=false, 범위 검사).
- 노트북 실측(진행 중): 설치된 TeamViewer 의 유휴 송신량 → 기준값 조정.
