# 말씀 표시 자료와 규칙 (기획자 확정 2026-11-11)

맑은물속교회가 공개하는 모든 프로그램이 똑같이 쓰는 자료다. 근거 문서는 구글 드라이브 "05_개발/통합프로젝트"의 "선교 구체화안".

## 파일

| 파일 | 내용 |
|---|---|
| `ko.json` | 구절 100곳(140절). 성경전서 개역한글판(침례 표기) |
| `dedication.ko.md` | "정보" 화면의 헌정 문구. 모든 프로그램이 같은 문구를 쓴다 |
| `church.ko.md` | [교회 안내]를 눌렀을 때의 문안 |

**이 세 파일의 글자를 고치지 않는다.** 다시 타이핑하지 말고 파일을 그대로 읽어 들이거나 빌드에 넣는다(`include_str!` 등). 줄바꿈과 띄어쓰기도 그대로 둔다. 본문 수정은 기획자(박정근)의 확인을 거쳐 이 파일에서만 한다. 화면에 맞추려고 구절을 자르거나 줄이지 않는다.

## 확정된 규칙

1. **항상 표시한다.** 끄는 설정을 만들지 않는다. 개인용·기관용을 나누지 않는다. 첫 실행 때 안내나 동의 창을 띄우지 않는다.
2. **표시하는 자리:** 시작 화면, 작업을 기다리는 화면(진행 표시 아래), 빈 목록 화면, "정보" 화면(헌정 문구와 [교회 안내]), 통합 화면의 "오늘의 말씀" 위젯.
3. **넣지 않는 자리(안전 규칙, 예외 없음):** 차단·종료 등의 확인 창과 승인 창, 경고·오류 알림, 진단 결과와 원본 출력, 감사 로그, 내보내는 파일. 사용자가 판단해야 하는 순간과 기록에는 섞지 않는다.
4. **표시 형식:** 본문, 그 아래 장·절(`ref`), 번역본 이름(`version`). 본문은 글자로만 표시한다.
5. **네트워크를 쓰지 않는다.** 구절은 프로그램에 내장한다. 몇 번 보였는지 세거나 어디로도 보내지 않는다. 교회 안내의 전자우편 주소는 글자로만 보이고, 누르면 사용자의 메일 프로그램이 열리는 것까지만 한다.
6. 프로그램마다 따로 덧붙이는 문구는 없다. 설교 영상 등 다른 링크도 넣지 않는다.

## 고르는 규칙 (모든 프로그램이 같은 날 같은 구절을 보이도록)

- `G` = `group`이 `gospel`인 구절 20곳(파일 순서), `O` = 나머지 80곳(파일 순서), `W` = `long`이 `false`인 구절(파일 순서, 96곳).
- **오늘의 말씀:** `day` = 사용자 PC의 현지 날짜가 1970-01-01부터 며칠째인지(1970-01-01이 0).
  - `day % 3 == 0`이면 `G[(day / 3) % 20]`
  - 아니면 `O[(day - day / 3 - 1) % 80]` (나눗셈은 정수 나눗셈)
  - 사흘에 한 번은 복음의 핵심 구절이 나온다. 무작위를 쓰지 않는다.
- **기다리는 화면·빈 화면·시작 화면:** `W`에서 차례로 돌린다. 시작 위치는 `day % len(W)`, 한 화면 안에서는 10초보다 빨리 바꾸지 않는다. `long`이 `true`인 구절(4곳)은 여기에 쓰지 않고 "오늘의 말씀"의 전체 보기에서만 보인다.

## 언어 선택 (기획자 확정 2026-11-12 — 방향. 구현 전에 설치 프로그램 문서를 확인한다)

- 설치 화면 첫 장에서 언어를 고른다. 기본 선택은 Windows 표시 언어. 목록에는 이 폴더에 말씀 자료(`<언어>.json`)가 있는 언어만 넣는다. "없음" 항목은 만들지 않는다.
- 화면 언어와 말씀 언어를 따로 저장한다. 설치 프로그램은 `HKLM\SOFTWARE\Antioch`의 `WordLang`, `UiLang`에 쓰고(모든 프로그램이 함께 읽는다), 설정에서 바꾸면 `HKCU\SOFTWARE\Antioch`의 같은 이름 값에 쓴다.
- 읽는 순서: HKCU → HKLM → Windows 표시 언어 → `en` → `ko`. 값이 내장 언어 목록에 없으면 다음으로 넘어간다. 값은 목록과 글자 비교만 하고 경로나 명령으로 쓰지 않는다.
- 설정 화면의 언어 항목은 바꾸는 설정이다. 끄는 항목을 넣지 않는다.
- 언어 파일은 `ko.json`과 같은 `id` 100곳을 같은 순서로 갖는다. `long`은 언어마다 다르다. "오늘의 말씀"은 `id`로 정하므로 어느 언어에서나 같은 날 같은 곳이다.
- 헌정 문구·교회 안내는 `dedication.<언어>.md`, `church.<언어>.md`. 없는 언어는 영어, 영어도 없으면 한국어 파일을 쓴다.
- **실린 언어: 한국어(`ko`), 영어(`en`, World English Bible — 기획자 확정 2026-11-14).** 영어는 구약의 하나님 이름을 'Yahweh'로 적는다. 헌정 문구·교회 안내는 `dedication.en.md`, `church.en.md`. 다른 언어를 더할 때는 번역본 사용 조건을 확인하고 그 언어를 아는 사람의 검수를 거친다.

## 대조가 남은 곳

`ko.json`의 `notes`에 적었다. 네 곳(`isa.55.1`, `psa.121.7-8`, `heb.4.12`, `act.1.8`)은 두 원문 자료의 글자가 달라 종이 성경과의 대조가 남아 있다. 구현에는 영향이 없고, 대조 뒤 다르면 `ko.json`의 `text`만 바뀐다.
