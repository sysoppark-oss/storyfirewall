## 3. 구현 순서(한 번에 하나, 설치판 확인 뒤 다음)

1. 용어 표(terms.ts)·화면 이름·처리 상태·조치 단추·국기 — 진행 중.
2. 심각도 4단계(judge Level 확장 + 칩·필터·토스트 기준 + 낮음 토글·요약 칩).
3. KPI 4 + 상단 띠 뱃지 + 전일 대비.
4. 이중 축 트래픽 그래프.
5. 심각 블록 + 킬체인/도넛 병렬 + 방어 피드.
6. 차단 통신 건수(FwpmNetEventSubscribe 집계) + 엔진 건강 뱃지.
7. 낮음 반복 승격(세 축).
8. 파괴 행위 자동 대응 규칙(서명자 예외, 되돌리기) — **완료**: GitHub Windows 러너(일회용 VM) 실집행 시험 A29 통과(2026-11-08, 끊기 10초·되돌리기 RolledBack), install-107.
9. 긴급 차단(기한부 정책 + 승인 창 + RDP 복합 조건) — 러너에서 먼저 시험(노트북 RAM 5.8GB 로 정식 VM 대신 러너 + Windows Sandbox, 사용자 결정 2026-11-07).
10. HUD: 트레이 아이콘 상태 표시(②) → 작은 상시 창(①) → 설정에서 선택.
