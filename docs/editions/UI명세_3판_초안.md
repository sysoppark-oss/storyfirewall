기준: UI 명세 2판. 이 초안은 2판에서 **바뀌는 장만** 적는다. 적지 않은 장은 2판 그대로다.
근거: 사용자 요청(2026-11-07) "실시간으로 문제를 찾아야 바로 해결가능함", "지금과 같은 것을 할 수 있는
분석이 프로그램에 필요함", "분류된 사건에 대한 추적이 반듯이 필요함", "사건을 파악하는데 개선이
필요함"과 카드 개편 스케치에 대한 답 "좋음". 구현 커밋: 60afdf5·6aaf9d0(지금 상태)·af4b945(Windows
알림)·f6ceb3b(판정 15초)·955940a(자동 조사)·이 초안과 같은 커밋(카드 개편).

## 2판 → 3판 바뀌는 점(요약)

1. 이야기 카드 = **요약(사슬 한 줄) → 결론(자동 조사) → 조치(권장 단추) → 자세히(탭 하나씩)**.
2. 카드 안에 카드를 넣지 않는다. 같은 모양의 반복은 카드 하나 + "발생 N번" 탭.
3. 카드에 "지금 상태" 줄(실행 중 / 끝남 / 확인 못 함).
4. 새 의심 사건 Windows 알림(창을 닫아도, 기본 켬) — 2판의 조용함 원칙 예외를 넓힘.
5. 흐름 보기의 "프로그램 자세히"는 좁은 옆 칸이 아니라 넓은 오른쪽 서랍(3-7 상세)으로 연다.

## 2-9. 같은 판정 묶음 (바뀜)

- 묶음 기준은 2판 그대로(같은 실행 파일 경로 + 서명 + 판정 규칙).
- 제목 칩 "N건" → **"N번"**(같은 모양이 N번 일어남). 제목 아래 회색 한 줄 "같은 모양 N번 · 처음 ~ 마지막".
- "발생 시각" 접힘 목록과 "이 사건 보기"(카드 안 카드)를 없앤다. 대신 자세히 탭 **"발생 N번"**: 줄마다
  시각 · 그 발생의 지금 상태 · 접속지(나라) · [이 발생의 흐름](그 자리에 흐름 보기만).
- 대시보드·다른 화면에서 묶인 사건으로 이동하면 그 카드의 "발생 N번" 탭을 열고 그 줄을 강조(2-11).

## 3-2. 오늘의 이야기 — 사건 카드 (바뀜)

```
[수준] 부모 → 주인공 → 실행한 프로그램(최대 3 + "외 N")  [N번]          마지막 활동 시각
       같은 모양 N번 · 처음 ~ 마지막            (묶음일 때)
       ● 지금도 실행 중 (PID n) | 지금은 끝남 (PID n) | 지금 상태 확인 못 함 (PID n)
       4칸 진행 · (파괴 징후 줄)
 ┌ 결론 ───────────────────────────────────────────────────────────────┐
 │ 권장: … · 판단 한 문장(사실만)                                       │
 │ ✓ / ✗ / · 확인한 사실 (지금 상태·경로·명령줄·부모·서명·등록 등)      │
 └──────────────────────────────────────────────────────────────────────┘
 자세히 [사실] [흐름 보기] [마인드맵] [발생 N번]        [이건 정상입니다] [여기서부터 끊기…]
 (누른 탭 하나만 아래 전체 폭으로)
```

- **제목(요약)**: 부모와 자식은 회색, 주인공은 굵게. 주인공 이름은 버튼(3-7 프로그램 상세). 전체 사슬은 툴팁.
  한 줄이 넘치면 말줄임(툴팁에 전체).
- **지금 상태 줄**: 시각을 넣지 않는다(시각은 오른쪽 위 마지막 활동 하나). 실행 중이면 --brand 점·글씨,
  아니면 --muted. "확인 못 함"의 이유는 툴팁("끝난 기록이 없고, 같은 번호(PID)로 떠 있는 프로세스가 같은
  프로그램인지 확인되지 않았습니다"). 단정 금지: 모르면 "실행 중 아님"이라고 쓰지 않는다.
- **결론(자동 조사)**: 서비스 story.investigate 결과. 첫 줄 = "권장: …" + 판단 한 문장. 펼치면 사실 목록.
  - 권장 문장 세 가지: "권장: 알려진 정상 모양 — 끊지 마세요" / "권장: 여기서부터 끊기" /
    "권장: 아래 사실을 보고 정하세요". 확신 말("보입니다")은 쓰지 않는다(D028-1).
  - 테두리: 알려진 정상 모양 = --brand, 위험 = --bad, 모름 = --line. 모름이면 닫힌 채로.
  - 파괴 징후(5장)가 있고 정상 모양으로 확인되지 않으면 "끊기"를 권한다.
  - 사실 표시: ✓(정상 쪽 근거, --ok) ✗(의심 쪽 근거, --bad) ·(정보·확인 못 함). 경로·명령줄·등록 이름은
    외부 문자열 — 자료로만 표시(제어·방향 바꿈 문자 제거, 길이 제한).
- **조치 단추**: 2-4·D1 순서 그대로 — 보조(자세히 탭) 왼쪽 → 주(이건 정상입니다) → 파괴적(여기서부터
  끊기…, 빨간 테두리) 오른쪽 끝. **빨간 채움 단추 0**. 권장 조치가 정상이면 "이건 정상입니다"를 주 단추(채움),
  끊기면 끊기 단추 테두리를 굵게 + "권장 · " 앞붙임.
- **자세히 탭**: 사실(2판 본문 항목·근거 배지·위치·서명·🕒/⚠ 줄) / 흐름 보기 / 마인드맵 / 발생 N번. 한 번에
  하나만 열리고, 다시 누르면 닫힌다. 기본은 모두 닫힘.
- "정상으로 표시할 수 없습니다" 안내 줄은 카드에 한 번만(2판 D044-3 그대로).

## 3-6. 설정 (추가)

- "알림" 절: [✓] 새 의심 사건을 Windows 알림으로 알리기(기본). 설명 "앱 창을 닫아 두어도(트레이) 사건이 한 장
  더 나아갈 때마다 한 번 알립니다. 원격 제어 시작 알림은 이 설정과 상관없이 늘 뜹니다."
- 알림 문장: 제목 "의심 사건: <프로그램 이름>", 본문 "<N장 이름>까지 이어졌습니다. 트레이 아이콘을 눌러
  '이야기'에서 확인하세요." 의도를 단정하지 않는다.

## 3-7. 프로그램 상세 (바뀜)

- 흐름 보기의 "프로그램 자세히"도 오른쪽 서랍으로 연다(옆 칸 안에 넣지 않는다 — 좁아서 한 단어씩 줄바꿈).

## 다음 판에서 붙일 것(설계 확정, 구현 중)

- **사건 추적**: 카드 제목 줄에 처리 상태 칩 "새 사건 / 조사됨 / 조치함(정상·끊음·지켜보기) / 닫힘", 처리 기록
  펼침, 이야기 화면 위 상태별 개수 + 필터(기본 "처리 안 한 사건"), 재발("같은 모양이 다시 나타남") 이어 붙이기.
- 프로세스에서 시작한 사건의 "이건 정상입니다"(예외 단위 = 부모 프로그램 → 실행된 도구 → 그 도구가 띄운
  프로그램, 경로 + 서명).
