## 해석 (개발 세션, 사용자 정정 가능)
- 흐름 보기는 1번(d045-flow)으로 한다. B안의 "그물 지도 흐름 보기"는 1번과 같은 자리를 차지하고 마인드맵과 겹치므로 채택 범위는 B안 HUD 로 본다.
- 2번(d045-hud, 터미널 겉모양 HUD)은 B안 HUD 로 대체된다.

## B안 HUD 구현 조건 (원칙에서 나옴)
1. 점 위치에 뜻: 거리 = 그 접속지를 처음 본 뒤 지난 시간(바깥 = 오늘 처음), 방향 = 프로그램별 구역. 점마다 근거 기록(연결 요약 행)에 이어진다 — "모든 표시는 근거에 연결" 원칙.
2. 늘 도는 빔 없음: 새 접속 기록이 들어올 때 한 번만 돈다. prefers-reduced-motion 이면 돌지 않음(D045 움직임 규칙 3).
3. 빨강은 판정(의심·파괴 징후)에만. 나라 표기는 UI 명세 2-8(국기 + 나라 · 조직).
4. 클릭 방식은 미정: (가) 늘 클릭 통과 + 트레이/단축키(권장) / (나) 단축키 누르는 동안만 입력.
