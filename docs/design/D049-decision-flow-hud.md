## 합치는 방법 (개발 세션 제안, 사용자 정정 가능)
1번과 B안은 둘 다 흐름 보기라 한 화면으로 합친다:
- 가운데 = B안 관계 지도(1번의 가운데 흐름 자리를 대신함)
- 왼쪽 = 1번 장 레일, 오른쪽 = B안 "선택한 것" 패널(폭이 1100 미만이면 장 레일을 위 가로 막대로 접음)
- 아래 = 1번 오늘 한 일 꼬리 + 상태 칩 + 단계 넘기기
- 겉모양은 라이트 기본 + 다크, 우리 색 토큰(UI 명세 2판 2-1). B안 목업의 어두운 바탕·청록 강조는 다크 테마에서만.

## 구현 조건 (원칙에서 나옴)
1. 흐르는 점선은 "실제 새 기록이 들어올 때 한 번"만 움직인다. 늘 흐르는 애니메이션 없음, prefers-reduced-motion 이면 정지(D045 움직임 규칙 3).
2. 주인공 상자의 빛나는 테두리는 늘 맥동하지 않는다 — 판정 빨강 테두리 고정.
3. 모든 상자·선은 근거 기록에 이어진다(선 = 출처 그래프의 선, 근거 원시 이벤트 id).
4. "이 접속지만 차단…"·"여기서부터 끊기…" 단추 순서: 보조 → 주 → 파괴적(빨간 테두리, 오른쪽 끝). 핵심 프로세스는 끊기 없음(D2).

## 채택하지 않은 것
- HUD(2번 d045-hud, 캔버스 A·B·C 안 HUD): 이번 결정에 없음 → 보류.

## 정정 (사용자 2026-11-06 21:09 "UI 적용이 안되어 있음")
- 위 "합치는 방법"에서 개발 세션이 제안한 "라이트 기본 + B안 겉모양은 다크에서만"은 사용자 뜻과 달랐다. B안 겉모양을 기본으로 바꾼다:
  - 기본 테마 = 어둡게(B안 팔레트: 바탕 #111315, 카드 #16191C, 선 #2A2E33, 글자 #E7E9EC, 보조 #8B929B, 강조 청록 #5EE6C8, 판정 #FF6B6B). 설정에서 밝게·Windows 따라가기 선택 가능.
  - 흐름 보기 상자는 열마다 색(출신 파랑 · 파일 황토 · 프로세스 청록 · 한 일 보라). 빨강은 주인공 테두리·파괴 징후(5장)·명령에만. 판정(1~4장) 선은 굵은 청록, 그 밖의 선은 청록 점선, 파괴 징후 선은 빨간 점선.
  - 움직임 조건(구현 조건 1·2)은 그대로: 늘 흐르는 점선·맥동 없음(주인공 빛은 고정).
