# Story Firewall

**내 PC의 연결을 "이야기"로 보여 주는 Windows 개인 방화벽** — 개발 중(출시 전)

> A personal firewall for Windows that explains every connection as a short story —
> *where it came from → what it ran → where it connected* — and lets you turn that story into a block rule.
> Local-only, no kernel driver, no TLS interception. Korean UI. **Work in progress, not released yet.**

---

## 무엇을 하는 프로그램인가

보통 방화벽은 "chrome.exe 가 142.250.x.x:443 에 접속"처럼 줄 하나를 보여 줍니다.
Story Firewall 은 그 연결이 **어디서 시작됐는지**까지 거슬러 올라가 한 편의 이야기로 묶습니다.

```
[의심] invoice.exe — 4장 외부 접속까지 진행
1장 유입   : 브라우저가 mail.example.com 에서 invoice.exe 를 내려받았습니다 (인터넷 표시 Zone 3)
2장 실행   : invoice.exe 가 실행됐습니다. 서명이 없습니다. 사용자 쓰기 가능 폴더(Downloads)입니다
3장 자리잡기: invoice.exe 가 로그인할 때 자동 실행되도록 등록했습니다 (Run 키)
4장 외부 접속: invoice.exe 가 처음 보는 해외 서버 203.0.113.7:8443 에 접속했습니다
→ [이 프로그램의 나가는 연결 막기]  [이건 정상입니다]
```

- 모든 문장은 실제로 기록된 사건(프로세스 생성, 파일 쓰기, 자동 실행 등록, 접속)에 연결되어 있고, 문장을 누르면 근거가 보입니다.
- "몰래 보내려 했다"처럼 **의도를 단정하지 않습니다.** 확인된 사실만 씁니다.
- 이야기에서 바로 차단 규칙을 만들고, 잘못 막았으면 되돌릴 수 있습니다.

## 주요 기능

| 기능 | 상태 | 설명 |
| --- | --- | --- |
| 연결 가시화 | 구현 | 프로세스별 TCP/UDP 연결·포트·사용량, 도메인(직전 DNS 조회와 짝지음), IP 의 등록 국가·통신사(오프라인 DB) |
| 이야기형 연결 분석 | 구현 | 유입 → 실행 → 자리잡기 → 외부 접속의 4장 판정, 프로그램별 평소 행동 기준선, 점수와 근거 |
| 마인드맵 | 구현 | 한 프로그램을 주인공으로 펼친 출처 그래프 |
| 정책(차단) | 구현 | 이야기에서 만드는 차단 규칙, 기한부 규칙, 적용 전 백업과 60초 안에 확인하지 않으면 자동 되돌림 |
| 설치 엑스레이 | 구현 | 프로그램을 설치할 때 무엇을 깔고, 무엇을 자동 실행에 등록하고, 어디에 접속했는지 한 장으로 |
| 첫 실행 관찰실 | 구현 | 인터넷에서 받은 서명 없는 프로그램이 처음 실행될 때 정해진 시간 동안 지켜봄 (끄기 / 알림만 / 나가는 연결 막기) |
| 브라우저 금고 경비 | 구현 | 브라우저가 아닌 프로그램이 브라우저 저장소(로그인 정보·쿠키)를 여는 것, 디버깅 모드 악용, 미끼 폴더 열기를 알림 |
| 변경 장부 | 개발 예정 | 관찰 대상이 바꾼 파일·자동 실행을 기록하고 되돌리기 |
| 원격 사기 경보, AI 에이전트 감시 | 개발 예정 | 원격 제어 프로그램을 이용한 사기, PC 에서 도는 AI 에이전트의 행동을 이야기로 |
| 내 AI 에게 묻기 (MCP) | 첫 출시 뒤 | 사용자가 쓰는 AI 앱이 읽기 전용으로 기록을 조회 |

## 어떻게 동작하나

- **수집**: Windows 내장 이벤트 추적(ETW)으로 프로세스·네트워크·DNS·일부 파일 이벤트를 받습니다. 파일 출신(인터넷에서 받은 표시), 디지털 서명, 자동 실행 위치, Windows Defender 기록을 함께 봅니다.
- **판정**: 규칙 기반 4장 판정과 프로그램별 평소 행동 기준선으로 점수를 매깁니다. 언어 모델(AI)은 판정에 쓰지 않습니다.
- **차단**: Windows Filtering Platform(WFP)을 사용자 모드에서 씁니다. **커널 드라이버를 설치하지 않습니다.**
- **구조**: 관리자 권한이 필요한 수집·차단은 Windows 서비스가 맡고, 화면(Tauri)은 일반 권한으로 실행해 네임드 파이프로 통신합니다. 정책 변경은 관리자만 할 수 있습니다.
- **보호 장치**: 이 앱 자신의 통신, 원격 데스크톱, 시스템 핵심 프로세스, 로컬 네트워크 기본 서비스는 실수로 막지 않도록 가드가 막습니다.

## 개인정보

- 수집한 기록과 연결 데이터는 **이 PC 안에서만** 처리하고 저장합니다. 사용자 동의 없이 밖으로 보내지 않습니다.
- 암호화된 통신 내용(페이로드)은 보지 않고, TLS 가로채기(MITM)도 하지 않습니다. 이야기의 재료는 메타데이터와 프로그램의 행동 순서입니다.
- IP 의 등록 국가·통신사(ASN)는 PC 에 들어 있는 오프라인 데이터베이스(DB-IP Lite)로 찾습니다. 등록 국가는 서버가 실제로 있는 위치와 다를 수 있습니다.

## 할 수 없는 것 (솔직하게)

- **백신이 아닙니다.** 파일 내용을 검사해 악성 코드를 찾지 않습니다. Windows Defender 와 함께 쓰는 것을 전제로 합니다.
- 드라이버 없이 동작하기 때문에 다른 프로세스의 메모리를 직접 읽는 방식, 커널 수준의 은닉은 볼 수 없습니다. 화면에도 그 한계를 밝힙니다.
- DNS-over-HTTPS 로 주소를 찾은 연결은 도메인 이름 없이 IP 로만 보일 수 있습니다.
- 판정은 "의심할 만한 순서"를 알려 줄 뿐, 악성이라고 단정하지 않습니다. 오탐이 있을 수 있고 "이건 정상입니다"로 고칠 수 있습니다.

## 지원 환경

- Windows 11 x64, Windows 10 22H2 x64
- 안드로이드판은 Windows 첫 출시 뒤 검토합니다.

## 진행 상황

- 핵심 엔진(수집·그래프·이야기·판정·정책)과 화면은 동작하며, 실제 PC 에서 시험 중입니다.
- 공개 배포(서명된 설치 파일)는 아직 없습니다.

Rust stable (MSVC), Node.js, Windows 10/11 x64
